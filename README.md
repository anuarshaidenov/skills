# skills

A collection of skills.

## Who it's for

Developers and founders who use agents and want ready-made workflows for tasks that sit next to the code, like making a landing page sell better.

## Skills

| Skill                                                  | What it does                                                                                                     |
| ------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------- |
| [`sell-the-outcome`](skills/sell-the-outcome/SKILL.md) | Audits landing page copy that sells features instead of outcomes, then proposes paste-ready rewrites. Read-only. |

## Install

usings skills.sh

```sh
npx skills@latest add anuarshaidenov/skills
```
